# vk Demo Vault

A small, self-contained vault that exercises every `vk` feature - kept
in the repo at `modules/features/vk/demo-vault/` and updated alongside
any change to `vk`'s Markdown/plugin/navigation surface (see that
directory's own `README.md` for how to try it live and what to update
when).

Start with [Project: vk Demo](materials/vk-demo-project.md) for the
tour, or browse Materials/Records/Texts below.
