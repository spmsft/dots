# Agent instructions for this vault

Shared conventions for every vault under `$HOME/Vaults` (structure,
frontmatter, linking, renaming, citations, validation) live in the
`AGENTS.md` at the Vaults root, one level up - read that first. This
file is only for anything specific to *this* vault.

Seeded once by `vk` and never overwritten afterwards - add whatever is
useful here as this vault grows (what it's for, any vault-specific
conventions beyond the shared ones).

## Persistent memory for this vault

Use `memory-bank/` (next to this file) for durable, agent-relevant
context specific to this vault - recurring themes, in-flight projects,
the user's own shorthand/conventions here, structural decisions. Plain
Markdown, no frontmatter required. Anything spanning more than one
vault belongs in `$HOME/Vaults/memory-bank/` instead.
