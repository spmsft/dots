# Assumptions

A dated log of assumptions introduced along the way. Every assumption
here is a candidate for later generalization or removal - the point of
this file is that nobody has to remember them, or rediscover them the
hard way when a proof mysteriously doesn't generalize.

Add an entry whenever you simplify the semantic model to make progress
(e.g. "assume determinism for now", "ignore the error case", "single
global store, no aliasing"). Include *why* it seemed reasonable at the
time, not just what was assumed.

## Format

```
## YYYY-MM-DD - <short description>

**Assumption:** <what was assumed>

**Rationale:** <why this seemed reasonable / what it unblocked>

**Risk if wrong / to revisit:** <what breaks if this needs lifting later>
```
