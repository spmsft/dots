# Review Findings

Independent review notes from the Reviewer role: hidden assumptions
found in proofs, theorems that technically typecheck but prove
something subtly weaker/different than intended, missing case analyses,
etc. A proof compiling is necessary, not sufficient - this file is
where "compiles but is this actually the theorem we wanted?" gets
answered.

## Format

```
## YYYY-MM-DD - <theorem/file reviewed>

**Reviewer:** <role/session>

**Finding:** <what was found - hidden assumption, over-strong hypothesis,
statement doesn't match `theorem-roadmap.md`'s stated purpose, etc.>

**Severity:** Blocking | Worth revisiting | Informational

**Resolution:** <what was done about it, or "unresolved - see
docs/architecture/open-questions.md">
```
