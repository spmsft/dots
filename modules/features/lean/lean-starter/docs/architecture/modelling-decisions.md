# Modelling Decisions

A dated decision log for LeanStarter's semantic model - the "why" behind
choices that shape everything downstream (which domain to model as a
partial function vs. a relation, which invariants to bake into a
`structure` vs. state as separate theorems, etc.). Mirrors
`memory-bank/assumptions.md` but for deliberate design choices rather
than simplifications-for-now: an assumption is "we're temporarily
ignoring X"; a decision here is "we chose X over Y, on purpose, and
here's why".

Do not silently re-litigate or contradict a logged decision - if new
information suggests one should change, log the change (with
rationale) rather than drifting away from it undocumented.

## Format

```
## YYYY-MM-DD - <decision>

**Context:** <what prompted the decision>

**Decision:** <what was decided>

**Rationale:** <why, and what alternatives were considered>

**Consequences:** <what this rules in/out downstream>
```
