# Open Questions

Unresolved semantic or design questions that need a decision (usually a
human's, sometimes the Semantic Architect role's) before related work
can proceed without guessing. If you hit a fork in the semantic model
and can't confidently pick a side, write it here instead of picking one
silently and hoping - a wrong guess here compounds into every theorem
built on top of it.

Move an entry to `modelling-decisions.md` once it's resolved, with the
resolution and rationale.

## Format

```
## <short question>

**Raised:** YYYY-MM-DD

**Why it matters:** <what's blocked on this / what it would change>

**Options considered:** <if any>
```
